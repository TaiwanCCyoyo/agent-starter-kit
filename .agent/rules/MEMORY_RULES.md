# Memory Rules

Memory is the **Soul** of the project and the communication hub between sessions. You MUST rely on it to ensure project continuity and avoid context amnesia.

1. **The Soul Protocol (Sync Ritual)**:
   - **Pre-Task (Always Mandatory)**: Read `.agents/memory/MEMORY.md` BEFORE starting research.
   - **Plan & Post-Task (Task-Dependent)**:
     - **Directive Tasks** (modifications, fixes): Perform Full Sync (update `Doing`, `Done`, and `Lessons Learned`).
     - **Inquiry Tasks** (read-only consultation): Perform Lightweight Sync (Read-Only) to minimize noise, unless a critical decision is made.

2. **The Mandatory Skill Alignment**:
   - ALL memory operations MUST follow the **`memory-maintenance` skill** to maintain a high Signal-to-Noise ratio.
   - Your contributions to Memory MUST be high-signal, concise, and structured.

3. **Initialize**: If `MEMORY.md` is missing, bootstrap it from `MEMORY.example.md` immediately.

4. **Learn and Delegate**: Record critical lessons to prevent repetitive debugging and explicitly delegate unfinished work to future sessions.
