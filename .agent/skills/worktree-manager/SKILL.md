# Worktree Manager

## Start

1. Identify the main repository and target worktree.
2. Confirm the branch goal through Antigravity planning or user alignment.
3. Run the repository's baseline verification in the new worktree.

## During Work

- Keep plans in Antigravity planning state, `.tmp/`, or maintained `docs/`.

## Finish

1. Verify the branch changes.
2. Merge or clean up the worktree only when explicitly requested.
