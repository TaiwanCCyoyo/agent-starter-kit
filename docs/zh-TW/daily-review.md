# 每日 PR 審核

擁有者授權範圍為 `TaiwanCCyoyo/agent-starter-kit` 的 `main`，每天台灣時間 23:00，以 `gpt-5.6-luna`、`high` 推理執行；完整契約見[英文版](../en/daily-review.md)。

- 開發 App 推任務分支、建立 PR；獨立審核 App 檢查後，可自行 Approve、合併，不需逐筆請擁有者批准。
- 檢查所有尚未完成的 PR；只自動處理開發 App 在本專案建立、非 draft、目標為 `main` 的 PR。
- 必須審閱最新 commit，確認 `repository-checks` CI 通過、沒有阻擋問題、衝突或未處理的審核討論。合併時指定已審核 SHA；內容更新就重新審核。
- 不確定、缺乏驗證或檢查失敗時留言並保留 PR。修正交回開發 session；不改規則、不強制合併、不改用個人身分。
- 擁有者接受同一台電腦上的可信 session：這是角色分工，不是防止惡意 session 互讀憑證的硬隔離。私鑰不進 repository，PR 程式不得在持有審核 token 的程序中執行。
- 排程與認證助手保存在本機，不從待審 PR 載入。排程依賴電腦與 Codex 可用；憑證、CI 或工具權限不可用時回報阻擋，不自行擴權。

下游專案須重新設定自己的身分、規則、排程與授權；複製文件不代表啟用。
