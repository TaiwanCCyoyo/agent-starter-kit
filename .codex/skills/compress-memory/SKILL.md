# Compress Memory

Follow `memory-manager`.

1. Preserve mission, constraints, current state, active decisions, unresolved work, and recent high-impact lessons.
2. Keep `MEMORY.md` at or below 2,200 chars and `USER.md` at or below 500 chars.
3. Keep `lessons.md` at or below 50 lines, with the most useful recent entries near the bottom.
4. Merge duplicate lessons and decisions.
5. Use `memory-sql` to graduate stale searchable entries after a deduplication query.
6. Move completed plans and non-searchable historical detail to `archive/`.
7. Do not create legacy taxonomy files or directories.
8. Run `skill-review` when compression reveals repeated procedural guidance better suited to a skill.
9. Report what was preserved, graduated, archived, merged, or dropped.
